# Baú do Minecraft

Aplicação web para gerenciar os itens e recursos do meu baú no Minecraft: cadastrar, listar, filtrar, editar e excluir.

## Tema e campos

| Campo | Tipo | Opções |
|---|---|---|
| item | texto | |
| tipo | categoria | Minério, Bloco, Ferramenta, Comida, Poção, Outro |
| quantidade | número | |
| local | texto | |
| raridade | categoria | Comum, Incomum, Raro |
| precisaDeMais | categoria | Sim, Não |
